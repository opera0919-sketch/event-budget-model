# 예상치 산출 원리 · 방법론 · 계산 과정 (상세)

연금저축 이벤트 시뮬레이션 보고서(`reports/연금저축_이벤트_시뮬레이션_보고서.xlsx`)의
예상치가 어떤 원리·절차·계산으로 산출됐는지에 대한 상세 설명.

## 0. 큰 그림 — 추정의 원리

이벤트 예산은 결국 **"몇 명에게 얼마를 주느냐"**로 결정된다. 문제는 "몇 명이 신청할지"를
좌우하는 상위 퍼널(광고 노출 → 페이지 도달 → 참여 클릭)이 내부에서 **관측되지 않는다**는
점이다(노출수·도달수·단계별 전환율 데이터 없음).

그래서 이 미관측 구간을 억지로 추정하지 않고, **관측 가능한 지표로 '신청자 수'를 직접
추정(reduced-form)**한 뒤, 그 아래 단계(신청→순입금→조건충족→지급)만 실측 비율로 전개한다.

추정 대상이 두 종류라 방법이 다르다:
- **(A) 진행 중 이벤트(5~7월)** — 부분 실적 있음 → **Nowcast(진행 추세 외삽)**
- **(B) 미래 이벤트(26.8월~)** — 실적 없음 → **take-rate 모델 예측**

---

## 1. 신청자 수 예측 — 미래 회차 (take-rate 2단계 모델)

미래 회차는 신청자 수는 물론 '기준 고객수'조차 비어 있어 2단계로 추정한다.

### 왜 take-rate인가
신청자 절대 규모는 연금저축 가입 고객 기반이 커질수록 늘어난다. 그래서 신청자를 그대로
예측하지 않고 **신청자 ÷ 기준 고객수 = take-rate(신청률)**로 정규화한다. 고객 기반 성장
효과를 제거해 회차 간 비교가 가능한 안정적 비율이 된다.

### Stage 1 — 기준 고객수 투영
연금저축 종료연월 고객수의 회차별 성장률을 계산해 미래로 연장한다. 성장에 계절성이 있어
(연말정산 시기 유입↑) **도착 시즌별 평균 성장률**을 쓴다.

```
마지막 실적 2026_02 = 1,836,227명
시즌 성장률: _03×1.0396 / _04×1.0746 / _01×1.0559
2026_03 = 1,836,227 × 1.0396 = 1,909,026명
2026_04 = 1,909,026 × 1.0746 = 2,051,354명
2027_01 = 2,051,354 × 1.0559 = 2,166,016명
```

### Stage 2 — 시즌 take-rate 적용
take-rate = (해당 시즌 과거 평균)과 (최근 4회차 평균)의 **50:50 블렌드**. 시즌 평균으로
계절성을, 최근 평균으로 프로그램 성숙(상승 추세)을 함께 반영한다. 초기 파일럿(2024_03) 제외.

```
예) 2026_03(_03 시즌): 시즌평균 0.94% 와 최근추세 1.25% 블렌드 = 1.10%
신청자(기준) = 1,909,026 × 1.10% ≈ 20,930명
```

### 시나리오 밴드
기준 take-rate에 ±CV(변동계수)를 적용해 보수/낙관을 만든다. CV는 그 시즌 과거 관측의
변동성(최소 0.15, 관측이 1개뿐인 시즌은 0.25).

```
2026_03: 보수 0.82% / 기준 1.10% / 낙관 1.37% → 신청 15,698 / 20,930 / 26,163명
```
2026_04·2027_01도 동일 절차(기준 신청 각 26,132 / 26,786명).

## 2. 신청자 수 예측 — 진행 중 5~7월 (Nowcast)

5~7월은 진행 중(잔여 7일)이라 '예측'이 아니라 **관측된 진행 추세를 최종치로 외삽**한다.

```
총기간 92일(5/1~7/31 가정), 잔여 7일 → 경과 85일
현재 누적 신청 16,356명 → 일평균 = 16,356 ÷ 85 = 192.4명/일
잔여 7일 추가 유입 = 192.4 × 7 × 계수  (보수 0.5 / 기준 1.0 / 낙관 1.5)
  기준: 192.4×7×1.0 = 1,347명 → 최종 신청 = 16,356 + 1,347 = 17,703명
  보수: +673 → 17,029명   /   낙관: +2,020 → 18,376명
uplift(확장배수) = 최종신청 ÷ 현재신청.  기준 = 17,703 ÷ 16,356 = 1.082
```
순입금·당첨은 신청과 같은 비율로 늘어난다고 보고(퍼널 비율 일정 가정) uplift를 곱한다.
```
최종 순입금(기준) = 10,459 × 1.082 = 11,320명
최종 당첨(기준)   = 5,315 × 1.082 = 5,753명
```
**계수의 의미**: 보수=잔여 유입이 일평균의 절반으로 둔화 · 기준=현재 속도 유지(선형) ·
낙관=마감 임박 유입 가속(1.5배).

## 3. 예산 산출 — 지급 퍼널 (조건충족 전원지급)

연금저축 이벤트는 추첨이 아니라 **조건 충족 시 전원 지급**. 지급 인원은 신청자 전체가
아니라 아래 2단계를 통과한 '당첨(조건충족)고객'이다.

```
신청 →(전환율=순입금/신청)→ 순입금 →(조건충족률=당첨/순입금)→ 당첨 → 전원지급
오늘자 5~7월 실측: 전환율 10,459/16,356 = 63.9%, 조건충족 5,315/10,459 = 50.8%
→ 지급률(당첨/신청) = 5,315/16,356 = 32.5%
리워드 단가 = 예산 ÷ 당첨 = 678,543,590 ÷ 5,315 = 127,665원 (=12.7665만원, 제세 포함)
```

**예산 공식**: `예산 = 당첨(조건충족)고객 × 리워드 단가`
```
5~7월 최종(기준): 5,753 × 127,665 = 7.34억
향후 2026_03 기준: 당첨 = 20,930 × 32.5% = 6,802명 → × 127,665 = 8.68억
```

### ⚠️ 흔한 오류 (정정)
지급률에 **'전환율(62%)'을 그대로 쓰면 안 된다.** 리워드는 순입금고객 전원이 아니라
그중 조건 충족한 44%(당첨)에게만 간다. 전환율로 계산하면 **순입금/당첨 = 2.26배 과대**.
반드시 `전환율 × 조건충족률` 두 단계를 곱해야 한다.

## 4. 가정 요약
- 5~7월 총기간 92일(5/1~7/31). 실제 기간이 다르면 일평균·잔여유입 재계산 필요.
- 잔여유입 계수 0.5/1.0/1.5 = 잔여기간 유입 패턴 가정(마감 급증 여부).
- 순입금·당첨이 신청과 동일 비율로 확장(퍼널 비율 일정) 가정.
- 향후 회차 지급률 32.5%(최근 실측). 10회차 평균 27.6% 적용 시 예산 ×0.85.
- 리워드 12.7665만원은 제세 포함 → 세금 미가산.

## 4-1. 몬테카를로 불확실성 (편성 안전마진)

3점 시나리오(보수/기준/낙관)는 결정론적이라 "상방 리스크가 얼마나 큰가"를 확률로 말해주지
못한다. 그래서 주요 변수에 **확률분포**를 부여해 40,000회 시뮬레이션하고 예산 분포를 얻는다.

- 신청자 = 기준 고객수 × take-rate(**삼각분포**: 보수/기준/낙관 꼭짓점)
- 지급률 = **Beta분포**(평균 32.5%, 실적 변동계수 CV 0.22 — 10회차 지급률 18~36% 산포 반영)
- 리워드 = 12.7665만원 고정
- 각 시행마다 예산 계산 → 분포. **P90(90퍼센타일)을 편성 권고치**로 제시.

| 회차 | 기대 | P50 | **P90(권고)** | P95 |
|---|---|---|---|---|
| 2026_03 | 8.67 | 8.53 | **11.53** | 12.45 |
| 2026_04 | 10.81 | 10.68 | **14.23** | 15.27 |
| 2027_01 | 11.09 | 10.95 | **14.55** | 15.62 |
| 3회차 합(포트폴리오) | – | 30.5 | **36.2** | 37.8 |

- **주의**: 3회차 합의 P90은 각 회차 P90의 단순합(40.3억)이 아니라 **합계 분포에서 직접**
  구한다(36.2억). 회차 간 변동이 부분 상쇄되는 분산효과 때문(단순합은 과대).
- 5~7월은 잔여 7일뿐이라 분포가 좁음(P90≈P50). 향후 회차는 불확실성이 커 P90이 기준보다 큼.

## 5. 한계
- 향후 회차 신청 예측은 take-rate 모델(고객기반) 산출로, 실제 이벤트 신청규모
  (분기 14~20천명)보다 높게 나오는 경향 → **상한 성격**. 실적 추세로 하향 보정 여지.
- 미래 이벤트는 실적이 없어 포인트 예측 검증 불가(26.8~10월 종료 후 첫 검증).
- 표본이 작아(시즌당 1~2개) take-rate 시즌평균의 불확실성 존재.
