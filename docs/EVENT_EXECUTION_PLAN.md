## 2. 현행 구조와 개편 필요성

### 2-1. 현행 구조
순입금 5백만원 이상 구간별 2만~100만원 지급.
**단, 순입금 1천만원 이상은 금액에 1.5배를 적용해 인정**하고 그 인정금액으로 구간 판정.

| 인정금액 구간 | 리워드 | 인정금액 구간 | 리워드 |
|---|---|---|---|
| 5백만~1천만 | 2만 | 5천만~1억 | 15만 |
| 1천만~3천만 | 4만 | 1억~2억 | 30만 |
| 3천만~5천만 | 6만 | 2억~3억 | 60만 |
| | | 3억 이상 | 100만 |

### 2-2. 확인된 한계

| 문제 | 실측 근거 |
|---|---|
| **배수로 인한 경계 왜곡** | 배수 때문에 실제 지급 경계가 순입금 **3,333만·6,667만·1.333억·2억** 등 비직관적 지점에 형성됨. 고객이 자기 리워드를 예측하기 어렵다 |
| **유효율 역진성** | 순입금 6~7천만 고객의 유효 리워드율 **0.234%** < 3~4천만 고객 **0.441%**. 더 많이 넣은 고객이 비율상 불리 |
| **유효율 분산 과대** | 급간별 유효율 0.23~0.47%, 가중 표준편차 **0.070** |
| **경계 절벽** | 5천만 경계에서 6만→15만 (**2.50배**). 경계 직전/직후 격차가 과대해 '경계 맞추기' 유인 발생 |
| **예산 변동성** | 회차별 최대 예산 **9.09억** (평균 7.96억 대비 +14%) |

## 3. 구간별 현행 대조 (핵심)

**동일 순입금 고객이 실제로 받는 금액** 기준. 현행은 배수로 인정금액을 올려 판정하므로,
구간 체계가 다른 신규안과는 이 방식으로만 공정하게 비교된다.

괄호는 현행 대비 비율. **볼드는 75% 미달 구간**.

구간 경계는 현행의 **실효 경계**(배수 역산: 3,340만 / 6,670만 / 1.334억 / 2억)로 나눴다.

### 3-1. 최저 보장 수준 (100만원 격자 정밀 검증)

| 안 | 최저 비율 | 발생 구간 |
|---|---|---|
| 안1 매력도우선 | 67% | 3,340만~5,000만 |
| 안2 균형 | 67% | 3,340만~5,000만 |
| 안3 효율우선 | 67% | 3,340만~5,000만, 6,670만~9,000만 |
| A안' 배수유지 | **75%** | 1,000만~2,000만, 1.334억 이상 |

### 3-2. 67% 구간에 대한 설명 (필독)

3,340만~5,000만 구간(인원 **16.8%**)은 현행 15만원 대비 10만원으로 **67%**가 된다.
이는 설계 실수가 아니라 **리워드 단위 제약의 결과**다.

- 리워드는 5만원 초과 시 5만원 단위만 허용 → **10만원과 15만원 사이 값이 없다**
- 75%를 지키려면 11.25만원 이상이 필요하나, 선택지는 10만원(67%) 또는 15만원(100%)뿐
- 15만원 적용 시 **예산 +9.6%p** (인원이 많은 구간이라 비용이 큼)

**선택지**: ① 67%를 수용(예산 절감 유지) ② 15만원으로 방어(예산 +9.6%p)
③ **만원 단위 허용을 검토** → 12만원(80%) 가능, 예산 +4%p로 절충

### 5-2. 두 갈래 선택

**A안'(배수 유지)와 안1~3(배수 폐지)은 서로 지배 관계가 아니다.**

| | 배수 유지 (A안') | 배수 폐지 (안1~3) |
|---|---|---|
| 강점 | 같은 예산대에서 매력도 96.2%·최저 75%로 우수. 구조 변경 최소로 시스템·약관 영향 적음 | 유효율 일관성(SD 0.043~0.058), 절벽 2.00x, 경계가 실제 금액과 일치해 고객 이해도 높음 |
| 약점 | 유효율 분산 0.077·절벽 3.00x로 설계 품질은 현행 수준. 역진성 잔존 | 3,333만~5,000만 구간 67% 하락. 배수 폐지에 대한 고객 커뮤니케이션 필요 |

**⚠ 중요**: A안'의 매력도 우위 일부는 **배수 적용 시 참여율 +3%** 가정에서 나온다.
이는 **실측이 아닌 모델 가정**이며, 제거하면 우열이 뒤집힌다(§8 리스크 ④).

### 5-3. 실무 권고

1. **예산 절감과 설계 개선을 함께 원하면 → 안2(균형)**. 예산 86%(worst 7.88억),
   매력도 93.4%, 유효율 분산 0.070→0.051, 절벽 2.50x→2.00x.
2. **매력도 방어가 최우선이면 → A안'**. 예산 85%에 매력도 96.2%, 최저 75%.
   구조 변경도 최소.
3. **공격적 절감이 필요하면 → 안3**. 예산 79%이나 6,667만~9,000만 구간도 67%로
   떨어지므로 민원 대응 준비 필요.
4. **최종 결정 전 배수의 참여 유인 효과를 실측 검증**할 것(§8 ④).

| ② | **배수 조건 폐지에 대한 고객 인식** | "혜택이 줄었다" 인식 | 경계가 실제 금액과 일치해 이해가 쉬워졌음을 강조. 3,000만~3,340만(167%)·5,000만~6,670만(100%)·9,000만 이상(100~200%) 구간은 유지 또는 상향됨을 함께 안내 |
| ③ | **흥행 시 예산 초과** | worst-case 7.88억 (평균比 +15%) | 예산을 worst-case로 확보. 신청 추이 모니터링 트리거 설정 [TBD: 초과 시 승인 절차] |
| ④ | **배수 참여보너스(+3%) 가정 미검증** | A안'과 배수 폐지안의 우열 판단이 뒤집힐 수 있음 | 배수의 참여 유인 효과를 A/B 테스트 등으로 실측. 검증 전에는 양안 병기 유지 |
| ⑤ | **탄력성 가정 오차** | 실제 참여가 모델보다 크게 감소 시 유치금액 미달 | 민감도 분석 보유 — 안2 매력도: 완만 95.2% / 기본 93.4% / **급격 90.0%**. 급격 시나리오에서도 90% 유지 |
| ⑥ | **5백만 미달자 민원** (인원 10.5%) | 신청했으나 미수령 | 자격 기준 사전 명확 고지 |

## 11. 부록

### 11-1. 산출 근거 및 가정

| 항목 | 내용 |
|---|---|
| 시뮬레이션 | 30회 반복(흥행 15 / 비흥행 15), 신청자 4,000~5,000명 |
| 분포 | 타사이전금액 실측 24구간 분포 + 회차별 ±15% 진동 |
| 구간 내 분포 | triangular (하한 쏠림 — 최소 기준만 맞추려는 성향 반영) |
| 수요 반응 | 비선형 로지스틱 S-커브. 소폭 하향엔 비탄력(sticky), 대폭 하향 시 급감 |
| 배수 참여 보너스 | 1.5배 +3% / 2.0배 +5% — **미검증 가정** |
| 제세 | 기타소득 22%, 리워드 5만원 이상 그로스업 |
| 시드 | 고정(재현 가능) |

**한계**: 탄력성 곡선 파라미터와 배수 보너스는 과거 실적이 없어 가정값이다.
이번 이벤트 실적으로 보정할 것.
