## 2. 현행 구조와 개편 필요성

### 2-1. 현행 구조
순입금 5백만원 이상 구간별 2만~100만원 지급.
**단, 순입금 1천만원 이상은 금액에 1.5배를 적용해 인정**하고 그 인정금액으로 구간 판정.

| 인정금액 구간 | 리워드 | 인정금액 구간 | 리워드 |
|---|---|---|---|
| 5백만~1천만 | 2만 | 5천만~1억 | 15만 |
| 1천만~3천만 | 4만 | 1억~2억 | 30만 |
| 3천만~5천만 | 6만 | 2억~3억 | 60만 |
| | | 3억 이상 | 100만 |

### 2-2. 확인된 한계

| 문제 | 실측 근거 |
|---|---|
| **배수로 인한 경계 왜곡** | 배수 때문에 실제 지급 경계가 순입금 **3,333만·6,667만·1.333억·2억** 등 비직관적 지점에 형성됨. 고객이 자기 리워드를 예측하기 어렵다 |
| **유효율 역진성** | 순입금 6~7천만 고객의 유효 리워드율 **0.234%** < 3~4천만 고객 **0.441%**. 더 많이 넣은 고객이 비율상 불리 |
| **유효율 분산** | 급간별 유효율 0.24~0.47%, 가중 표준편차 **0.044** (고객별 유효율을 인원 가중한 값) |
| **경계 절벽** | 5천만 경계에서 6만→15만 (**2.50배**). 경계 직전/직후 격차가 과대해 '경계 맞추기' 유인 발생 |
| **예산 변동성** | 회차별 최대 예산 **9.09억** (평균 7.96억 대비 +14%) |

### 3-1. 최저 보장 수준 (100만원 격자 정밀 검증)

|---|---|

**모든 안이 전 구간에서 현행의 75% 이상을 지급한다.** 리워드 단위를 1만원으로
바로잡은 결과다(12만·13만 같은 중간값 사용 가능). 5만원 단위를 가정했던 초기
설계에서는 3,340만~5,000만 구간이 67%, 6,670만~7,000만 구간이 50%까지 떨어졌다.

### 5-2. 배수 유지 vs 폐지 — 계량 지표는 배수 유지가 우세

같은 최저 보장률(80%) 기준으로 **A안(배수 유지)이 안2(배수 폐지)를 예산·매력도·유효율
분산 전 항목에서 앞선다**(예산 77% vs 82%, 매력도 94.2% vs 92.8%, SD 0.034 vs 0.044).

| | 배수 유지 (A안) | 배수 폐지 (안1~3) |
|---|---|---|
| 강점 | 계량 지표 전반 우세. 구조 변경 최소로 시스템·약관 영향 적음 | 경계가 실제 순입금과 일치해 **고객이 자기 리워드를 예측 가능**. 배수 로직 제거로 운영 단순화 |
| 약점 | 경계가 3,333만·6,667만 등 비직관적 지점에 형성돼 이해가 어려움. 배수 로직 유지 부담 | 같은 보장률에서 예산이 더 든다 |

**⚠ 중요**: A안의 우위 일부는 **배수 적용 시 참여율 +3%** 가정에서 나온다.
이는 **실측이 아닌 모델 가정**이다(§8 리스크 ④). 남는 선택 기준은
**계량 지표(배수 유지)** 대 **고객 이해도·운영 단순성(배수 폐지)** 이며,
후자는 수치로 환산되지 않으므로 정책 판단이 필요하다.

### 5-3. 실무 권고

1. **계량 지표를 우선하고 구조 변경을 최소화하려면 → A안(배수 유지)**.
   예산 77%(worst 7.02억), 매력도 94.2%, 최저 보장 80%.
2. **고객 이해도·운영 단순화를 우선하려면 → 안2(균형)**.
   예산 82%(worst 7.46억), 매력도 92.8%, 최저 보장 80%. 경계가 실제 금액과 일치.
3. **매력도 방어가 최우선이면 → 안1**. 예산 90%, 매력도 94.9%, 최저 보장 **85%**.
4. **공격적 절감이 필요하면 → 안3**. 예산 79%, 다만 최저 보장이 75%로 가장 낮다.
5. **최종 결정 전 배수의 참여 유인 효과를 실측 검증**할 것(§8 ④).

| ② | **배수 조건 폐지에 대한 고객 인식** | "혜택이 줄었다" 인식 | 경계가 실제 금액과 일치해 이해가 쉬워졌음을 강조. 1,000만~3,340만 구간은 현행 유지 또는 상향(최대 200%), 1.3억~1.334억·1.7억~2억 구간도 상향됨을 함께 안내 |
| ③ | **흥행 시 예산 초과** | worst-case 7.46억 (안2 평균比 +15%) | 예산을 worst-case로 확보. 신청 추이 모니터링 트리거 설정 [TBD: 초과 시 승인 절차] |
| ④ | **배수 참여보너스(+3%) 가정 미검증** | A안'과 배수 폐지안의 우열 판단이 뒤집힐 수 있음 | 배수의 참여 유인 효과를 A/B 테스트 등으로 실측. 검증 전에는 양안 병기 유지 |
| ⑤ | **탄력성 가정 오차** | 실제 참여가 모델보다 크게 감소 시 유치금액 미달 | 민감도 분석 보유 — 안2 매력도: 완만 94.7% / 기본 92.8% / **급격 89.6%**. 급격 시나리오에서도 약 90% 유지 |
| ⑥ | **5백만 미달자 민원** (인원 10.5%) | 신청했으나 미수령 | 자격 기준 사전 명확 고지 |

## 11. 부록

### 11-1. 산출 근거 및 가정

| 항목 | 내용 |
|---|---|
| 시뮬레이션 | 30회 반복(흥행 15 / 비흥행 15), 신청자 4,000~5,000명 |
| 분포 | 타사이전금액 실측 24구간 분포 + 회차별 ±15% 진동 |
| 구간 내 분포 | triangular (하한 쏠림 — 최소 기준만 맞추려는 성향 반영) |
| 수요 반응 | 비선형 로지스틱 S-커브. 소폭 하향엔 비탄력(sticky), 대폭 하향 시 급감 |
| 배수 참여 보너스 | 1.5배 +3% / 2.0배 +5% — **미검증 가정** |
| 제세 | 기타소득 22%, 리워드 5만원 이상 그로스업 |
| 리워드 단위 | **1만원 단위**(전 구간). 당초 '5만원 초과는 5만원 단위'로 가정했으나 현행에 6만원 티어가 실재해 틀린 가정이었다 |
| 유효율 계산 | 고객별 유효율을 인원 가중 평균(급간 평균 금액에 리워드를 적용하면 편향 발생) |
| 하락률 검증 | 100만원 격자(1천만원 격자는 좁은 구간의 하락을 평균에 묻는다) |
| 시드 | 고정(재현 가능) |

**한계**: 탄력성 곡선 파라미터와 배수 보너스는 과거 실적이 없어 가정값이다.
이번 이벤트 실적으로 보정할 것. 특히 배수 보너스(+3%)는 A안과 배수 폐지안의
계량 비교를 좌우하므로 실측 검증이 가장 중요하다.

